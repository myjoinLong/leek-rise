# UI架构设计与开发底线约束

## 1. 技术栈与架构分层（铁律）
- 语言：TypeScript (strict) + Vite。
- 渲染：UI 全部使用原生 DOM + CSS，**绝不可用 React/Vue**。
- 引擎：Phaser 3 **只允许**用于交易界面的 K 线渲染，严禁污染其他 UI。
- 核心层（`src/core/`）：必须纯 TS，禁止出现任何 DOM / window / Phaser 代码。状态管理用自研 reducer。
- 数据：严禁写死，必须通过 Zod 校验 JSON 配置表驱动。

## 2. 视觉基调（像素风）
- 拒绝任何纯文字占位符页面！必须是像素风交互。
- 全局引入硬阴影（box-shadow: 4px 4px 0px #000），减少圆角。
- 暗黑赛博背景色，涨红（#E85D4A），跌绿（#3FB87A）。

## 3. 开局与场景交互（Daytime Hub）
- **StartScreen**：暗黑风，瀑布流下跌红K线背景。选角：【男骑手】vs【女主播】。
- **Daytime Hub**：一个横版像素风街道地图。包含四个可点击节点：
  1. 烧烤摊（触发龙哥对话）
  2. 当铺（触发九哥借贷）
  3. 外卖车（点击打工）
  4. 交易所（进入 Trading 阶段）
- 点击节点应弹出像素风对话框（带NPC头像），而不是切网页。

## 4. 交易屏与真实盘口
- 必须展示：真实的下单量、吃单推高/砸低价格、散户挂单明细、实时成交流水（Tape）。
- **成交反馈卡（核心痛点）**：
  - 正常停留 2500ms，异常（大滑点/延迟/部分成交）4000ms，拒绝必须手动关闭。
  - 展示委托价与成交价的差额，用琥珀色警告（⚠），但**绝不解释原因**，仅偶尔提示“网络拥堵”。
  - 装死按钮（去结算）永远可用，无二次确认。
