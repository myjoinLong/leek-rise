# P2-v17 小镰刀直播副本与周结浏览器验收

- 日期：2026-10-30
- 本轮角色：产品/玩法策划、经济系统工程师、浏览器 QA。
- 目的：验收与调查类龙哥副本玩法不同的经营型副本，核对操作选择、收入/流量反馈、回街区和每周平台分成是否贯通。
- 环境：隔离 Vite `4174`、`?artPreview=1` 正常游戏入口，新建男性角色；该预览模式不读写存档，不触碰现有玩家档案。无状态注入。

## 流程与观察

1. 从开始页 → 早盘 → 街区 → 小镰刀对话进入直播间。页面提前说明每段精力消耗、收入计算方式、女性角色收入加成和周流水分成。
2. 选择“实测后讲优缺点” → “停下来认真答疑” → “说明真实价格与条件”。每一步都即时扣 5 点精力并反馈热度、信任和成交意向变化；进度分别显示为热度 33/41、信任 62/70、成交意向 2/4。
3. 完成三段后一次结算：收入 ¥90、精力消耗 15、现金 ¥3,200→¥3,290、粉丝流量 15→18、热度 46、信任 80。结果页逐项回显三个选择和变化；回街区后直播入口显示“今日已开播”。
4. 继续到第7天且不再直播。周结账单实际显示利息 -¥90、房租 -¥240、会员费 -¥30、设备费 -¥60、平台分成 -¥4.50、今日净变动 -¥424.50；现金 ¥3,290→¥2,955.50，负债 ¥18,000→¥18,090。平台分成等于本周直播流水 ¥90 的 5%。

## 结论与边界

- 直播玩法不是对话领奖：玩家在三段运营中选择短期成交和长期信任取舍；选择结果经 Core 结算，且流量状态反馈回街区/夜间账本。
- 已验证男性诚实路线的一次完整收入结算和一次第7天周结。此路径的屏幕信息足以解释本次计算；本次没有测试夸大宣传路线、女性加成、直播中途退出、刷新续玩、多尺寸/触屏、多个随机种子或长线经济平衡。
- 一次 ¥90 收入与 ¥4.50 分成仅证明实现链路，不证明收入公平、路线最优或长期可持续；利率与周期固定成本仍是待调原型参数。
- 本轮未改源码、经济参数或存档；没有新增产品决定，不把已有原型描述成正式平衡。下一步按矩阵继续验收其他玩法，并补直播小视口及中途退出/恢复边界。

## P2-v18 结算小视口滚动修复与角色路线回归

- 480px 内容列、720px 高视口正常入口复测女性角色诚实路线：收入 ¥114（基础 ¥95 × 1.20）、现金 ¥3,200→¥3,314、精力100→85、流量30→34；完整回执与返回按钮可见。之前 P2-v17 的男性路线与第7天周结证据仍有效。

- `npm run build`、`npm run lint`通过，保留 Phaser 大 chunk 提示；未运行测试或改 Core/存档。未验夸大宣传策略、直播退出/刷新、多种子长线平衡及真实触屏。
