# P2-e14 扫地僧仓位复盘桌

## 事实、假设与待决

- 已确认方向：NPC 有独立场景、真实操作、Core 结算、回执与回 Hub；风险与选择可理解，不能藏必败概率。
- 本轮实现：仓位配置桌，而非读图选择题。每段输入 0–100 的整数百分比，先看投入及压力损失，再提交揭晓固定历史后续。可主动超预算，也可空仓。
- 实施假设：虚拟初始资金 ¥10,000，逐段压力损失预算 ¥300，每段扣真实精力 4，开始至少 12 精力；每日一次，开始即占次数，中途退出不退精力、不再进入，当天真实工作名额不受影响。
- 三段教学样本：压力情景分别为投入部分下跌 12%/10%/5%，后续收益率 +6%/−8%/+2%。数值集中于 Core policy/cases，场景文字在 UI；这些是合成教学片段，不是从玩家当前股票抽取的真实交易记录。
- Core 按当前虚拟资金、投入百分比及收益率计算分位盈亏，逐段复利；列出同起点满仓的单段对照。压力情景不是最大可能损失，不计算段内最大回撤。
- 回执统计预算内段数和模拟盈亏；空仓算遵守预算但可能错过上涨，超预算也可能碰巧盈利。不按事后涨跌判断选择对错。
- 不改变真实现金、负债、仓位、情报、每日收入和费用；无现金奖励，不自动交易。固定样本和评分仅为原型，不是投资预测或正式游戏经济平衡。
- 待决：真实历史案例来源、样本变化、风险预算可配置性、练习难度、成长/知识解锁与长期激励；尚未实现这些机制。
