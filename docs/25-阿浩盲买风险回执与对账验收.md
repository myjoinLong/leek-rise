# P2-v25 阿浩盲买风险回执与对账验收

## 角色与范围

- 角色：玩法设计、经济风险可读性与副本 QA。
- 验收对象：阿浩旧机回收中，不验机直接买入风险机型时，玩家是否能从线索、结果回执和现金账本理解亏损原因。
- 不改副本价格、胜率、精力成本、存档结构或其他活动规则。

## 发现与修正

- 浏览器试玩发现：玩家未验机时，Core 仍把结算写成“验机结果”，误将成交后揭晓包装成事前检查；负数也显示为“净收益 −¥240”。
- 回执现在区分两种信息时序：花精力检查后写“验机发现”；未验机购买则写“未验机收购，成交后才发现”。未验机回执不再展示伪装成玩家检查结论的诊断文字。
- 每笔回执现在明确玩家选择、转售价、收购价、整备费和净收益/净亏损；班次累计标题改为“本班盈亏”。

## 浏览器风险样本

在本地 `artPreview=1` 隔离流程中选择男角色、从街区进入阿浩副本，全程不验机，连续三台均按标价直接转卖：

| 货品 | 回执机况 | 转售价 − 收购价 − 整备费 | 现金变化 |
|---|---|---:|---:|
| 轻薄旗舰机 | 成交后揭晓：外观轻微使用痕迹，主要功能正常 | ¥770 − ¥620 − ¥0 = +¥150 | ¥3,200 → ¥3,350 |
| 续航旧款机 | 成交后揭晓：电池健康度偏低 | ¥510 − ¥460 − ¥0 = +¥50 | ¥3,350 → ¥3,400 |
| 低价大屏机 | 成交后揭晓：主板有进液腐蚀痕迹 | ¥180 − ¥420 − ¥0 = −¥240 | ¥3,400 → ¥3,160 |

- 班次合计 −¥40，与现金净变化一致；精力仍为 120，因为三次都未验机。
- 页面直接显示各次成交结果、事前是否验机、买卖选择与费用算式；最终回执能解释第三笔亏损及总账差额。

## 自动化检查与边界

- `phoneFlip.test.ts` 覆盖未验机亏损与已验机亏损的不同文案；本轮定向测试 8 项通过。
- `npm run build`、`npm run lint` 通过；构建仍有既存 Phaser chunk 约 1.37 MB 的体积提示。
- 本轮只覆盖第 1 天这组三台确定性样本，不证明整体收益、盲买风险、精力成本或长期经济已平衡；也不是正式数值定案。小视口、存档和其他路线的边界沿用 docs/23、docs/24。


## P2-v106 旧机报价的资金占用预览

- `quotePhoneFlipOffer`将报价预览与回收单据的计算收拢在 Core：未验机时只显示采购现金和整备预留，不展示机况对应的转售价差；完成验机后显示所选方案的资金占用、估算净收益和成交转卖后的预计现金。
- UI 的按钮可用性继续使用原有现金校验；Core 成交规则、报价、利润、精力、风险和市场经济均未改变。议价预览按“若成交”口径，不预先揭示卖家是否接受还价。
- `phoneFlip.test.ts`覆盖未验机不泄露收益、验机后预计现金对账和现金不足时禁用报价。此项把“资金会影响后续交易与进货”的取舍放到选择当下，不构成现金锁定或保本承诺。
