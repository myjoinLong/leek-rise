## 阿浩：现金经营与风险判断

1. 第一单验机后议价收购 ¥558，直接以 ¥770 转卖，净收益 +¥212；验机消耗 3 点精力。
2. 第二单验机发现电池健康度 69%、换芯约 ¥90；按 ¥460 收购并整备，以 ¥670 转卖，净收益 +¥120；再消耗 3 点精力。
3. 第三单验出主板进液，预计维修 ¥300 且返修风险高；拒绝收购，保住现金。
4. 回执逐单列出检查发现、买入、整备、转卖和净收益。现金 ¥3,200→¥3,532，精力 120→111，班次净收益 +¥332；返回街区后工作名额显示已用。

操作差异来自信息价值与资金决策：验机先花精力，随后比较议价、整备和放弃；验机前只显示卖家线索与“机况未核实”，验机后显示可计算的结果区间。已成交收益与未成交风险单独显示。

## 龙哥：信息调查与判断

- 三步分别核对原始来源、成交明细和公开公告；每步都能选择深入核查或表面观察。
- 本样本发现原始消息无正式出处、买卖成交方向不明、公开公告无方向性内容；选择“证据还不够”后，回执解释暂不把传闻当交易信号，并提示“情报可信度：较高”。
- 该情报不发现金、不耗精力、不自动下单；返回街区后显示今日已调查，进入交易屏后 NewsHint 显示龙哥来源及“先观望”线索。现金仍为 ¥3,532，精力仍为 111。

## 产品判断与边界

- 这一组同日流程证明现金副本与信息副本可以并行：前者产生可对账现金收入并消耗工作名额，后者提供不直接改钱的交易信息；结果进入各自账本/交易提示。
- 阿浩的验机、议价和整备构成可学习的经营循环；龙哥的三类证据和“证据不足”结论构成不同的调查循环，不是换皮领奖。
- 这是一个固定样本和一次浏览器流程，不代表其他路线的可读性、交易风险平衡、真人理解度、窄屏/触屏体验或经济通关率。
- 下一步按相同口径对照配送或咖啡现金路线，并试玩真实下单/成交回执，核验风险、费用和净变化能否逐项解释。
