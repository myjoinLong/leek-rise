# P2-v26 郑师傅维修副本窄屏操作验收

## 角色与范围

- 角色：移动端产品体验、玩法 QA。
- 验收对象：郑师傅电驴维修班的症状阅读、检测选择、维修选择和结算在小视口下是否可读、可触达。
- 本轮只调整维修屏的辅助字号与窄屏滚动区，不改 Core 规则、收入、精力、存档或依赖。

## 调整

- 检测结果、检测/维修按钮说明、班次进度、精力余量和工单记录从 8–9px 提到 10px。
- 高度不超过 700px 时，可滚动操作区最大高度从 62% 调为 70%，让新增文字尽量留在首屏。
- 检测与维修按钮仍至少 48px 高，结束/返回按钮至少 44px 高。

## 浏览器验收

在本地 `artPreview=1` 隔离流程中，男骑手第 1 天由街区进入郑师傅副本：

1. 第一单检测电池，显示“电池组压差偏大，负载电压明显下坠”；选择正确维修，到账 ¥30。
2. 第二单症状指向刹车，故意选错电池，只拿 ¥18 底薪。
3. 第三单正确维修控制器，再得 ¥30。
4. 结算展示底薪 ¥54、质量奖 ¥24、累计收入 ¥78、精力 −17、剩余 103；现金从 ¥3,200 到 ¥3,278。点击“回到盘城街区”后现金、精力和当日工作锁正确显示。

- 320×568 活动态：检测诊断、三类维修选择与退出按钮均可见；页面无横向溢出。
- 568×320 结算态：主容器宽 480px 并居中；文档宽度等于视口宽度 568px；回执内容高 216px、滚动容器内容高 216px；44px 返回按钮可见且点击后成功回街区。
- 浏览器错误日志为空。该流程使用 `artPreview=1`，不读取或覆盖已有存档。
