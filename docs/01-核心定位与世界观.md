# 《韭菜翻身》核心定位与世界观

## 1. 一句话定位
**《韭菜翻身》**：一个你想靠炒股翻身，却发现股市是台“情绪收割机”的黑色幽默模拟游戏。你以为在交易股票，其实在给大哥、老师、主播、庄家和借贷公司发工资。

核心口号：**“十次交易，九次反向；剩下一次，手续费。”**
真结局不是财务自由，而是：**不赌为赢。**

## 2. 世界观：盘城
表面是金融新城，实际由几大势力控制：
- **庄家联盟**：控制“剧本股”，负责制造消息、拉盘、出货。
- **流量平台**：主播、股神老师、财经MCN，靠散户注意力赚钱。
- **借贷网络**：九出十三归，专门接爆仓的人。
- **打工系统**：普通公司、外卖、夜班、代驾，稳定但消耗精力。
- **监管影子**：偶尔出现，既是希望也是NPC博弈工具。
- **地下群聊**：大哥喊单、内幕消息、杀猪盘、会员费。

主角：负债入场，想靠炒股翻身。表面上“还清债务/赚到第一桶金”，实际隐藏目标是**离开牌桌**。

## 3. 核心循环与时间线
一天分四个时段：
1. **早盘前**：看消息、群聊、主播喊单、NPC私聊。
2. **白天**：打工/做流量/跑腿/当托/出卖体面换钱。
3. **交易时段**：买入、卖出、加仓、割肉、借钱、装死。
4. **深夜复盘**：心态结算、债务结算、人设结算、NPC关系变化。

**时间节奏（重点）**：
- 交易阶段每 3 秒跳动一次 K 线（一个 Tick），一天 60 个 Tick（约3分钟）。
- 玩家可随时提前结算（装死）。完整一天体验约 5-8 分钟，极其适合碎片化。
- 每周结算：房租、利息、会员费、设备费、流量分成。玩家永远在“现金流”和“心态”之间挣扎。

## 4. 股市机制：隐性收割（绝不写死90%）
不要每笔固定反向，而是用**隐藏剧本+动态收割**：
- 每只股票有隐藏剧本：吸筹、拉升、出货、砸盘、假反弹。
- 玩家仓位越高、越像散户、越跟消息，越容易被“针对”。
- 反向通过：**滑点、延迟成交、假突破、利空突袭、强平线、手续费、会员费、借贷利息**实现。
- 玩家看到的是毛收益；真实收益扣完各种费，很多玩家“赢了盘面，亏了总账”。

## 5. 终极破局路线（L1-L5）
- L1 新手：跟大哥，亏。
- L2 发现反向：故意反买，被延迟成交和假突破打。
- L3 元游戏：识别剧本周期，控制仓位，只吃高赔率段，赚庄家预算。
- L4 社会工程：联合散户、曝光主播、举报庄家、做空流量人设。
- L5 真突破：不靠炒股稳定盈利，把股市当提款机一次套利后离场。
- **隐藏结局：“你成了新的庄家”**——你终于赚钱了，但主角变成NPC，开始收割下一个你。
