## 2. 男女角色差异（重玩价值）
- **男主（外卖骑手）**：抗压（心态上限高）。白天偏体力打工（外卖/代驾）。容易遭遇“苏姐”杀猪盘。
- **女主（带货主播）**：流量变现快（初始名声高）。白天偏情绪价值（直播/当托）。容易遭遇“K线菩萨”骗拜师费。

## 3. 搞钱方式（抽象化、系统化）
绝不直白色情。“卖身”用**出卖时间/形象/隐私/体面**来隐喻。
- **打工**：稳定低收益，耗精力。
- **出卖体面**：陪酒应酬、当托、背锅、假扮男友。消耗“体面值”换现金。
- **反差人设**：白天社畜，晚上股神；越反差流量越高，但人设与真实值差距越大，崩盘越惨（社死结局）。
- **流量**：发亏损复盘、卖惨、揭秘庄家。
- **信息差**：跑腿、代排队、群聊情报。
- **当托**：帮大哥喊单，赚小钱但“韭菜度”大增。
- **后期卖课**：玩家自己也能成“老师”，进入镰刀结局。

## 4. 防挫败与长线防长草设计
- **信息碎片**：每次失败给线索（如：“你发现龙哥喊单后30分钟总有异常卖单”）。让玩家觉得**不是随机被搞，是在看穿系统**。
- **二周目视角**：解锁“元游戏视角”，显示庄家剧本和NPC KPI。
- **高手的防线（防无限套利）**：
  - 第10天利息翻倍，第20天房租涨租（逼你交易）。
  - 庄家发现你不上当，直接停牌或制造假利好。
  - 资金变大后，强制拉入高摩擦成本的“私董会”。

## 5. 商业化（IAA 广告变现）
包装成“与魔鬼的交易”：
- **免息复活（激励视频）**：面临强平时，看广告免一天利息。
- **绝密内幕（激励视频）**：早盘看广告解码消息（真假随机）。
- **插屏广告**：深夜进入结算页时自然加载。
