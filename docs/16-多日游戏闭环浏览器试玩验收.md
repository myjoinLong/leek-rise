# 多日游戏闭环浏览器试玩验收

日期：2026-10-30  
身份：体验验收  
环境：本地 Vite，`http://127.0.0.1:3000/?artPreview=1`。`artPreview` 跳过本地存档读写，本次过程不会覆盖用户存档。

## 流程与观察

1. 选择“男：外卖骑手”，进入第 1 天早盘，再进入白天街区。屏幕展示连续像素街区底图及 11 个分布式 NPC/地点触发入口；交易所入口独立显示。
2. 从“工作入口 · 外卖驿站”进入外卖副本。每单显示情境线索、路线风险、预期收入和精力成本。选择小巷（¥62 / -12）、主路连廊（¥58 / -12）、加速冲单（¥64 / -22）后完成三单。
3. 副本回执显示收入 ¥184、消耗精力 46；返回街区后现金从 ¥3,200 增至 ¥3,384，精力从 120 降至 74，其他共用工作入口标记为今日已工作。
4. 进入交易所，按当前盘口提交买入 100 股。界面显示成交价 ¥10.03、交易费用 ¥1.50；现金从 ¥3,384 降至 ¥2,379.50，持仓从 800 股增至 900 股，最新价与实时成交明细同步更新，并以星标突出玩家成交。
5. 提前结束交易日。夜间账本显示交易盈亏 +¥25、费用 -¥1.50、今日净变动 +¥23.50；选择进入下一天后到达第 3 天早盘，再进入街区时现金和持仓进度仍保留。

## 验收结论与边界

- 本次浏览器手动试玩证实：选角 → 早盘 → 街区 → 独立副本操作 → Core 结算 → 回街区 → 交易 → 夜间账本 → 次日早盘，可以连续走通。
- 本次只验证一条外卖路线和一笔买单；没有覆盖其他副本、卖单/部分成交/拒单、刷新中断、手机小视口、60 Tick 自动收盘或周期费用日。
- 这是流程验收样本，不是经济平衡结论。工资、交易盈亏和持续生存还需结合多策略模拟与多名玩家试玩评估。
- `npm test` 未配置脚本；直接运行 `npx vitest run`，30 个测试文件、225 项通过。`npm run build` 与 `npm run lint` 通过。构建仍报告 Phaser `PriceChart` 分块大于 500 kB。
