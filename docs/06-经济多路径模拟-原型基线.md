# 多路径经济模拟：原型基线

> 2026-10-30，P2-e1：已实现可重复执行的纯逻辑模拟；不是正式平衡、章节通关或浏览器验收。

> 结果时点：第 2–7 节的表格是 P2-e1 旧行情历史基线。P2-e2 至 P2-e9 的更新结果见本文末尾，不得把旧表当作当前行情的结果。

## 来源与可重复运行

- 直接调用 createInitialState、gameReducer、盘口成本估算和现有外卖规则；没有复制收益、手续费或行情公式。模拟模块不进入主路由，不改变玩家规则。
- 运行：`npx vitest run src/core/simulation/economySimulation.test.ts`；矩阵入口为 `runPrototypeEconomyMatrix()`，返回配置、逐日账本、汇总与最终状态。
- P2-e1 矩阵为 126 组合＝7 策略 × 2 角色 × 3 Tick 档 × 30/60/90 天。当前矩阵扩展到 162 组合＝9 策略 × 2 角色 × 3 Tick 档 × 30/60/90 天，新增 STREAM、WORK_STREAM；每组从独立新游戏开始，固定现有随机种子。重复运行逐项相等。
- 现有测试覆盖矩阵重现、现金/债务/持仓恒等式、逐日净变动对账、劳动/直播收入、精力恢复、贷款不算利润、真实清仓撮合、路线差异与非法配置。

## 实施假设（均非正式数值）

- 每天走早盘→街区→交易→夜间；0/20/60 Tick 是敏感性试验，0 为不等待行情的对照，不确认自动收盘规则或日内时长。
- 跑单按 ALLEY→MAIN→RUSH，收入与耗能取真实配置；每日只结算一次。另测 MAIN→ALLEY→STEADY 的较低收入路线。
- WORK 保留原型初始 800 股；WORK_CASH 首日完成工作后清仓再持币。两者区分劳动现金流和继承的市场风险。
- 低频与重仓策略每 5 Tick 观察一次，只读取当前价及已产生的倒数第 4 个价格：上涨买入、下跌卖出；低频每次最多 100 股，重仓买入盘口估算可负担的整百股、下跌卖全部。不是最优策略或真人判断模型，不读取 scriptPhase。
- 借贷路线仅首日借一次现有 ¥1,000，再每天跑单；不模拟不存在的还款、合同、利息。提前离场按真实撮合清空初始持仓后不再交易。
- 保留初始现金、债务与仓位；两种角色选相同路线，均能负担精力。固定种子是回归基线，不是多随机种子统计置信区间。

## 发现与产品偏离

- 劳动能赚钱：较优路线每天 ¥184，较低收入路线 ¥108；30 天分别贡献 ¥5,520/¥3,240。清仓后跑单净资产持续增加，证明当前原型已有可恢复路径；不代表负债自动还清或达到第一章目标。
- 默认持仓风险很大：每日 60 Tick 时，持仓不动 30 天亏 ¥7,512，抵消最优跑单收入后仍亏 ¥1,992。玩家未主动下单也会因初始仓位受损，应在初始仓位/风险说明及行情调平阶段处理。
- scriptEngine 的四段漂移在当前配置下长期下偏（上涨和下跌幅度不对称）；本矩阵的两条简单趋势策略均未在非零 Tick 档获得 30 天净增益。不能据此声称交易永远不可能盈利，也不能声称盈利机会已验证充分。
- BORROW_WORK 与 WORK 净资产变化相同，现金和债务各多 ¥1,000；借款提供流动性，不创造收入。现九哥仍为点击即借款的占位逻辑，没有合同玩法，未满足独立副本契约。
- 利息/生活成本为零，债务未还款；第 30 天只普通跨日，60/90 天延续是现有 reducer 事实，不能当成债务重组已完成。

## P2-e2：行情方向性与开局成本基准（2026-10-30）

- 阶段漂移：积累 -0.15%～+0.15%、拉升 -0.05%～+0.35%、派发 -0.15%～+0.15%、下跌 -0.35%～+0.05%/tick；每阶段 10 tick。拉升/下跌均值约 ±0.15%/tick，积累/派发均值为 0；完整周期均值接近 0，保留趋势段和逆向波动。
- 虚拟成交流的主动买入率跟随阶段：积累 58%、拉升 72%、派发 42%、下跌 25%。这是价格剧本的可读线索，并非保证方向的算法。
- 初始持仓仍为 800 股，但 `avgCost` 改为开局现价，不再以 11.85 高于约 10 元的开局报价制造立即浮亏。集中持仓风险仍保留，未宣称开局净资产为正。
- 龙哥副本改为按所选股票的当前 `scriptPhase` 生成对应调查案例，使它与正在运行的市场剧本对齐；消息内容依旧是游戏脚本原型，不使用外部公告数据。
- 多种子探索：将原 126 配置扩展到 5 个固定初始种子，共 630 次真实 reducer 模拟（男性、60 Tick/日、30天）。净资产变化区间/中位数：IDLE -¥680～+¥1,168 / -¥72；WORK +¥4,840～+¥6,688 / +¥5,448；WORK_CASH +¥5,488～+¥5,500 / +¥5,497；LOW_FREQUENCY -¥1,449～-¥37 / -¥1,104；HEAVY -¥23～+¥1,564 / +¥839。HEAVY 有 4/5 组正收益，IDLE 有 2/5 组正收益。
- 90天的 5 种子结果：IDLE -¥1,376～+¥1,096（2/5 正收益）；HEAVY +¥42～+¥2,707（5/5 正收益）；WORK +¥15,184～+¥17,656，主要由累计劳动收入 ¥16,560 驱动；LOW_FREQUENCY 五组仍为负。该策略集很小、固定种子仅五组，不能据此代表玩家或所有市场。
- 结论：结构性单边下跌已消除；趋势重仓策略在当前简化行为下有温和收益，但低频滞后交易持续亏损，需调整/解释这个落差。工作收入提供清楚的恢复路径。所有结果仍未包含利息、生活费和债务偿还，也未包含第30天重组。
- 验证：630 组由本地 Vite SSR 调用现有 reducer 模拟入口计算，不是自动化测试；`npm run build`、`npm run lint` 通过，Vite 仍报告压缩后约 1.57 MB 主 chunk 超过 500 kB。
- 参数和规则均为原型假设；五种子与这些交易机器人不代表最终平衡结论，试玩后可调整，不能视为收益承诺。

## P2-e3：小镰刀直播路线与收入敏感性（2026-10-30）

- 新增两个 reducer 驱动的策略：STREAM 每天只做直播；WORK_STREAM 每天跑默认外卖路线再做直播。直播有 3 段，每段消耗 5 点精力；模拟使用诚实实测/认真答疑/透明成交路线。男角直播基础收入，女角初始粉丝更多且直播收入 ×1.2。
- 当前收入公式：成交意向点数 × ¥10 + `floor(最终热度 / 10) × ¥5`，女性角色再乘 1.2；口碑/粉丝通过每轮信任和热度变动计算。所有系数是原型值，非正式平衡。
- 用 5 个固定种子跑当前 162 配置矩阵，共 810 个 reducer 模拟。聚焦男性、60 Tick/日：30 天净资产变化范围/中位数：WORK +¥4,840～+¥6,688 / +¥5,448；STREAM +¥2,220～+¥4,068 / +¥2,828；WORK_STREAM +¥7,740～+¥9,588 / +¥8,348；WORK_CASH +¥5,488～+¥5,500 / +¥5,497；HEAVY -¥23～+¥1,564 / +¥839。以上每种策略 5/5 为正，但不含利息、生活费、还款及第30天重组。
- 90 天同一子集：WORK +¥15,184～+¥17,656 / +¥16,176；STREAM +¥7,524～+¥9,996 / +¥8,516；WORK_STREAM +¥24,084～+¥26,556 / +¥25,076；WORK_CASH +¥16,528～+¥16,540 / +¥16,537；HEAVY +¥42～+¥2,707 / +¥1,019。样本仅 5 种子、策略路线固定，不能代表玩家行为或证明长期平衡。
- 结果提示：直播本身可形成低精力收入，叠加跑单的日程在当前能量规则下可完成，女角成交加成更高。总收入仍受开局持仓市场波动影响；后续需模拟女性、不同直播策略、失败/中途退出和高低信任的完整组合，并纳入生活费用与债务偿还后再调收入系数。
- 验证：`npx vitest run` 23 项通过；`npm run build`、`npm run lint` 通过。此项为本地 Vite SSR 下的 Core 策略模拟，不是浏览器体验验收；主 bundle 约 1.59 MB，Vite 有 >500 kB 警告。


## P2-e4：主动还款、现金保留与清债时间（2026-10-30）

- 入口：`runRepaymentEconomyMatrix()`（src/core/simulation/repaymentExperiment.ts）。种子 4/17/42/2026/65535；6 策略 WORK/STREAM/WORK_STREAM/WORK_CASH/HEAVY/BORROW_WORK × 两角色 × 30/60/90天 × 不还款/保留0/1000/3200元 × 5种子＝720组。每日60 Tick，外卖和诚实直播路线沿用真实规则。这是独立实验矩阵，不更改默认162组合。
- 夜间还款额为 min(剩余本金, max(0, 现金－保留额))，调用真实 reducer；保留额须为非负、可安全表示的整分金额。不自动卖股，不预先保护次日交易预算，不模拟利息/生活费。缺省 repayment 保留历史不还款行为。

## P2-e5：周期成本与第30天危机入口（2026-10-30）
