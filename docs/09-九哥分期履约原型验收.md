# P2-e13 九哥分期履约原型

2026-10-30；本轮角色：产品/系统规则、数值情景、核心与UI工程。依据 docs/05 的透明结算、可选择恢复及危机后继续存档方向；没有委派代理或新增正式产品决定。

## 可审查的规则

- 第30天危机后，九哥协商中先核账、证明真实收入，再选择免费自动还款；与现有一次宽限和付费降息三选一。点击入口不直接发钱。
- 原型参数单独放在 `debtInstallmentPolicy`：最多8次足额还款期，每期最多300元。没有签约费，不调整现行利率。
- 每次周结先计现有利息、房租、会员、设备和平台分成，再从现金还款；不变卖股票。还款同时减少现金和欠款，不算费用或收益。
- 若可用现金不足，部分支付并保存缺口，随后暂停；不罚款、不追加债务，不把已存在的欠款重复记成新债。暂停周不占期；夜间恢复后从下一次未结周结继续。缺口不滚入下一期追偿。
- 夜间可取消后续计划；已还金额不退，本次协商不能重签。第8次足额还款后计划结束，即使仍欠款；最后一期如有缺口仍暂停且不占期。不能将期满称为清债或通关。
- 手动或自动还清全部欠款会停止计划并解除当前危机标记；游戏与存档继续。此为现有清债条件的延伸，最终章节目标、正式危机退出与再协商规则仍待决。
- 计划不承诺收入、降息或盈利。自动还款试算忽略“每期计划偿债”输入，只执行计划扣款；暂停后不自动恢复。其他三方案仍按输入试算。所有试算只操作快照。
