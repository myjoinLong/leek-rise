# P2-v24 阿浩旧机回收副本小视口验收

## 角色与范围

- 角色：移动端产品体验与副本 QA。
- 验收对象：阿浩手机回收副本在窄屏竖屏/短横屏下的可读性、滚动与操作闭环。
- 只调整 `PhoneFlipScreen.ts` 的短屏滚动区与辅助文字字号；没有改 Core 结算、玩法数值、存档或依赖。

## 调整

- 高度不超过 700px 时，副本内容最大高度从视口的 63% 增至 77%，减少 320×568 首屏的空白，让标价和议价操作更容易被发现。
- 旧机选项说明和成交历史从 9px 增至 10px。
- 高度不超过 420px 时隐藏场景招牌，避免短横屏里招牌挤占操作空间。

## 浏览器验收

在 320×568 的独立 artPreview 流程中，从选角走到盘城，进入阿浩副本后完成：

1. 验机并议价直接转卖，净收益 +¥212；刷新恢复已由 P2-v23 正常模式另行验过。
2. 验机并按标价整备转卖，净收益 +¥120。
3. 验机发现主板进液腐蚀后放弃，避免额外亏损。
4. 结算显示本班 +¥332，现金 ¥3,532，精力 111；点击返回后到达街区。

首单验机前的四种买入方式均可见；验机说明展开后内容可滚动到议价按钮。触摸按钮盒尺寸均不小于 44×44px，页面无横向溢出。结算回执在短屏内完整显示且返回按钮可直接点击。

另以 568×320 检查结算态：内容在滚动区域内，滚动到回执底部后“回到盘城街区”按钮可操作，页面无横向溢出。
